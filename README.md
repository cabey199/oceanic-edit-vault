# Oceanic Archive

Build a ultra-luxurious, production-grade Web App called "Oceanic Edits Archive" — a private digital video storage and streaming platform for an edit creator. 

TECH STACK & ARCHITECTURE:
- Modern React, Tailwind CSS, Framer Motion animations, Lucide React icons.
- Fully responsive, mobile-first design optimized for Safari and Chrome on mobile devices.

DESIGN TOKENS & AESTHETIC:
- Background Deep: #060A17 (Rich abyssal navy-black)
- Surface Cards: #0B132B (Deep ocean navy) with frosted glassmorphism (backdrop blur, subtle border: rgba(72, 202, 228, 0.18))
- Primary Accent: #48CAE4 (Bioluminescent Cyan glow)
- Secondary Accent: #0077B6 (Deep ocean blue)
- Text Main: #F8FAFC, Text Muted: #94A3B8
- Overall feel: Ethereal, dark mode, high-end private lounge, fluid ocean motion.

LAYOUT & COMPONENT REQUIREMENTS:
1. Floating Header Navigation:
   - Left: Logo "HERNAME.ARCHIVE" with a glowing cyan dot indicator.
   - Right: Sleek outline "Upload New Edit" CTA button (cyan glow hover) and a Secret Lock icon.

2. Fullscreen Hero Section:
   - High-impact dark ocean ambient video background (or CSS wave particle animation with dark overlay).
   - Centered Badge: "[ PRIVATE DIGITAL VAULT ]" in cyan monospace text with border.
   - Headline: "An aesthetic space for every edit."
   - Subtitle: "Unlimited storage, instant downloads, crafted for your raw & finished edits."
   - Interactive CTA: "Explore Vault" button that smooth-scrolls down.

3. Video Gallery Grid (Main Vault):
   - Filter bar: "All Edits", "TikTok / Reels (9:16)", "Landscape", "Favorites".
   - Grid of glassmorphism video cards featuring hover autoplay/preview, high-definition thumbnails, video title, file size badge (e.g., "12.4 MB"), date tag, and two interactive action buttons: "Watch Fullscreen" and "Download MP4".

4. Secret Easter Egg:
   - Tucked into the footer: A tiny, subtle cat icon with opacity 0.3. Clicking or hovering shows a glowing cat paw ripple animation or toggles the Developer Vault view.

Please build this complete foundation with rich, realistic placeholder data, fluid animations, and pixel-perfect design.
